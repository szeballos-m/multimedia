Ejecutable (.exe)

Convertir todo el proyecto en una aplicación ejecutable (.exe) independiente

Esto es muy común cuando entregás un trabajo profesional a un cliente, porque les permite abrir el kiosco como si fuera un programa de PC (un juego o un software de gestión), sin que nadie sepa que atrás hay un servidor o un navegador web.

Hay tres formas principales de lograrlo, desde la más sencilla hasta la más profesional:

Opción 1: Crear un Acceso Directo Lanzador (La solución más simple)

No empaqueta el servidor, pero crea un icono ejecutable que abre Chrome directamente en modo kiosco bloqueado.

  1. En el escritorio de Windows, hacé clic derecho ➔ Nuevo ➔ Acceso directo.
  2. En la ruta del elemento, pegá esto (ajustando tu carpeta y URL):

Plaintext

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "http://localhost/my-app/"

  1. Ponele de nombre "Iniciar Kiosco Museo".
  2. (Opcional) Hacé clic derecho en el acceso directo ➔ Propiedades ➔ Cambiar icono... y elegí el logo del museo o un icono de pantalla.

Al hacer doble clic, abre la aplicación inmediatamente a pantalla completa.

Opción 2: Empaquetar con Nativefier (Convierte la Web en una App de Escritorio)

Nativefier es una herramienta gratuita que toma cualquier dirección web (incluso tu localhost) y la envuelve dentro de una estructura de Electron.js. Genera una carpeta con un archivo .exe propio.

Pasos:

  1. Necesitás tener instalado Node.js en la computadora.
  2. Abrís la consola de comandos (CMD) y ejecutás:

npm install -g nativefier

  1. Para crear el ejecutable del kiosco, corrés:

nativefier --name "KioscoMuseo" "http://localhost/my-app/" --full-screen

  1. Te va a generar una carpeta con un ejecutable llamado KioscoMuseo.exe. Al abrirlo, se ejecuta como una aplicación nativa de Windows sin barras ni bordes de navegador.

Opción 3: Un servidor portable auto-contenido (La solución Portable Profesional)

Si querés llevarte el proyecto en un pendrive o instalarlo en la PC del museo sin tener que instalar UwAmp ni importar la base de datos a mano:

  1. Podés empaquetar toda la carpeta de tu servidor local (UwAmp) junto con un script .bat o un instalador creado con Inno Setup o WinRAR (archivo auto-extraíble).
  2. El script de inicio hace tres cosas en segundo plano al hacer doble clic en el .exe:
    • Arranca Apache y MySQL de forma silenciosa.
    • Espera 3 segundos.
    • Abre Chrome o la app en modo kiosco apuntando a http://localhost/my-app/.

¿Qué es lo ideal?

  • La Opción 1 (Acceso directo con parámetros --kiosk) es excelente porque les enseña a usar comandos del sistema operativo.

Si querés sumar un desafío técnico o punto extra, usar Nativefier (Opción 2) para que generar un .exe real con el icono del proyecto es un cierre espectacular para la materia
